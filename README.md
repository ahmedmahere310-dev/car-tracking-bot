# نظام التحكم المركزي في حركة السيارات والمعدات — بوت تليجرام

## المرحلة الحالية (اللي جاهزة دلوقتي)
- قاعدة بيانات كاملة (فروع، أصول، طلبات نقل، سجل تدقيق، تاريخ الأكواد)
- تسلسل الموافقات الأربع (إدارة عليا → رئيس قطاع → مدير فرع → مدير مخازن)
- **توليد كود جديد تلقائي** للعربية عند اكتمال الموافقات (زي C-001 → BHT-115)
- سجل تاريخ الأكواد (تعرف كل عربية كانت كودها إيه قبل كده وإمتى اتغيّر)
- تحقق أمني: مفيش حد يوافق على مرحلة مش بتاعته
- أمر `/status` لمتابعة أي طلب

## لسه مش موجود (خطوات جاية)
- تنبيهات SLA (24 ساعة تذكير / 48 ساعة تصعيد للبديل الاحتياطي)
- توليد QR كود فعلي وربطه بحارس البوابة
- التمييز بين المعدات ذاتية الحركة والمنقولة

## التشغيل خطوة بخطوة

### 1. التثبيت
```bash
npm install
```

### 2. الإعدادات
انسخ `.env.example` إلى `.env` وحط فيه توكن البوت اللي تاخده من BotFather على تليجرام:
```
TELEGRAM_BOT_TOKEN=123456:ABC-your-token-here
DB_PATH=./db/data.sqlite
```

### 3. تجهيز قاعدة البيانات
```bash
npm run init-db
```

### 4. استيراد بيانات العربيات الحقيقية (من ملف الإكسل اللي عملناه)
```bash
node src/importFromExcel.js "قاعدة_بيانات_الأصول_بالأكواد_الموحدة.xlsx"
```

### 5. تسجيل الموافقين (لسه محتاج تعمله يدوي بالـ SQL أو نبنيلك سكريبت استيراد زي العربيات)
مثال لإضافة موافق:
```sql
INSERT INTO approvers (role, branch_code, full_name, telegram_id, backup_telegram_id)
VALUES ('branch_manager', 'C', 'خالد', '123456789', '987654321');
```
الأدوار المتاحة: `top_management`, `sector_head`, `branch_manager`, `warehouse_manager`
لو الدور شامل كل الفروع (زي رئيس القطاع أو الإدارة العليا) سيب `branch_code` فاضي (NULL).

### 6. تشغيل البوت
```bash
npm start
```

## استخدام البوت
- `/newrequest` — يبدأ طلب نقل جديد (هيسألك: كود العربية → كود الفرع المستقبِل → السبب)
- `/status 5` — يعرض حالة الطلب رقم 5
- أزرار ✅ موافقة / ❌ رفض بتظهر تلقائي لصاحب الدور المطلوب في كل مرحلة

## ملاحظة مهمة
كل ما تكتمل نقلة، الكود بيتغيّر فعليًا في قاعدة البيانات — يعني لازم إجراء يدوي مصاحب: طباعة QR/كود جديد ولصقه على العربية بدل القديم عند بوابة الفرع المستقبِل، عشان الكود في النظام يفضل مطابق للكود الفعلي على الأرض.
